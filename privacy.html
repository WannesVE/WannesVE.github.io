Privacy Policy

Last updated: 24 November 2026

This policy explains how Sleep Relax Studio ("the application") handles information. The application is a private tool used only by its owner to upload videos to the owner's own YouTube channel.

YouTube API Services

The application uses YouTube API Services. By using the application you agree to the YouTube Terms of Service. Information handled through YouTube API Services is also subject to the Google Privacy Policy.

What information is accessed

  • An OAuth access token for the owner's own Google account, which allows the application to upload videos and set thumbnails on the owner's own YouTube channel.
  • The ID and URL of videos the application has uploaded, so the owner can find and review them.

The application does not access, collect or store any information about viewers, other users or other channels, and it does not read comments, analytics or personal data.

How information is used

The token is used only to upload the owner's own original videos (as private) and to set their thumbnails. Nothing else is done with it.

Storage and sharing

  • The token is stored as an encrypted secret in the owner's private automation environment and on the owner's own computer. It is never published.
  • No information is sold, shared with or disclosed to third parties.
  • No cookies or tracking technologies are used by the application or by this website.

Retention and deletion

Video IDs are kept in a private log for as long as the owner uses the application. Access can be revoked at any time via the Google security settings page; after revocation the stored token no longer works and is deleted by the owner.

Changes

If this policy changes, the updated version will be published on this page with a new date.

Contact

Questions about this policy can be sent through the contact options on the associated YouTube channel.
